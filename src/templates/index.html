Обучающий центр

1

Начните с рисования

Перейдите в раздел приложения и нарисуйте цифру от 0 до 9 на холсте. Не беспокойтесь о аккуратности — нейросеть обучена распознавать разные стили письма.

Совет: Рисуйте цифры крупно, занимая большую часть холста
2

Выберите модель ИИ

Экспериментируйте с разными архитектурами нейронных сетей:

  • Perceptron — простейшая модель для понимания основ
  • MLP — многослойный перцептрон для более точного распознавания
  • CNN — сверточные сети для работы с изображениями

3

Наблюдайте процесс распознавания

В режиме реального времени смотрите, как нейросеть анализирует ваш рисунок:

Изображение →
Предобработка →
Анализ нейросетью →
Результат

4

Анализируйте результаты

Изучайте подробную статистику распознавания:

  • Распознанная цифра с процентом уверенности
  • Распределение вероятностей по всем цифрам
  • Визуализация внутренней работы сети
  • Сравнение разных моделей между собой

5

Углубляйте знания

Используйте теоретические разделы сайта для понимания:
